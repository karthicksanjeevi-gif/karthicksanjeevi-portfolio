# karthicksanjeevi-portfolio

Personal portfolio website with admin dashboard.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Copy `.env.example` to `.env` and add your Firebase/MongoDB credentials
3. Run the app:
   `npm run dev`
4. Open `http://localhost:3000`

## Admin Login

Open `http://localhost:3000/admin.html` and sign in with your Firebase user.
